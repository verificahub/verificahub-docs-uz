# Условия обработки данных конечных пользователей

Дата вступления в силу: 12.11.2026

*Перевод. При расхождении текстов преимущество имеет текст на узбекском языке.*

Настоящие условия являются неотъемлемой частью [Публичной оферты](./public-offer.md) и применяются к данным Конечных пользователей, которые Интегратор передаёт через API Verificahub.

## 1. Роли

1.1. В отношении данных Конечных пользователей **Интегратор** является собственником персональных данных, а **Verificahub** — оператором, обрабатывающим их по поручению Интегратора и только для оказания услуг.

1.2. Verificahub не использует эти данные в собственных целях — для рекламы, профилирования, продажи или передачи третьим лицам.

## 2. Данные

- номер телефона Конечного пользователя (+998);
- OTP-код;
- идентификатор, статусы и временные метки Сессии подтверждения;
- статусы доставки, полученные от операторов связи;
- технические параметры, переданные вместе с запросом Интегратора.

Интегратор не передаёт в параметрах запроса (например, в полях metadata) избыточные персональные данные.

## 3. Цели

- отправка и проверка OTP-кода;
- предоставление статусов и отправка уведомлений webhook;
- учёт отправленных сообщений и расчёты;
- предотвращение мошенничества и злоупотреблений;
- рассмотрение претензий и споров.

## 4. Порядок обработки

4.1. Номер телефона в открытом виде используется только на время, необходимое для отправки SMS, и передаётся провайдеру SMS-шлюза.

4.2. В базе данных номер телефона хранится в виде хеша. В журналах Платформы номер маскируется.

4.3. OTP-код не хранится в открытом виде и проверяется только в течение срока действия Сессии подтверждения.

4.4. Дальнейшие действия Интегратор выполняет по идентификатору Сессии подтверждения.

## 5. Привлекаемые лица

5.1. Для оказания услуг Verificahub может привлекать поставщиков услуг: SMS-шлюзы, мобильных операторов, серверы и дата-центры. Они обрабатывают данные только в объёме, необходимом для выполнения своих функций, не используют их в собственных целях и обязуются обеспечивать конфиденциальность и безопасность.

5.2. Verificahub отвечает перед Интегратором за действия привлечённых лиц.

## 6. Локализация

Данные Конечных пользователей хранятся на серверах на территории Узбекистана. Трансграничная передача осуществляется только с соблюдением требований законодательства.

## 7. Сроки хранения

| Данные | Срок |
|---|---|
| OTP-код | срок действия Сессии подтверждения |
| Записи Сессий подтверждения (хеш номера, статусы, время, стоимость) | 12 (двенадцать) месяцев — для расчётов и претензий |
| Журналы (номера маскированы) | 90 (девяносто) дней |

По истечении срока данные удаляются или преобразуются в обезличенную статистику. При прекращении договора Интегратор может запросить досрочное удаление; записи, необходимые для расчётов, хранятся в соответствии с требованиями закона.

## 8. Безопасность

Verificahub применяет шифрование TLS, хеширование и маскирование, ограничение прав доступа, мониторинг входов и обязательства сотрудников о конфиденциальности.

## 9. Инциденты

При выявлении инцидента безопасности, затрагивающего данные Конечных пользователей, Verificahub уведомляет Интегратора без необоснованной задержки, по возможности в течение 72 часов, и принимает меры по устранению последствий.

## 10. Обращения субъектов

Конечные пользователи по вопросам своих данных обращаются к Интегратору. Если обращение поступило в Verificahub, Verificahub перенаправляет его Интегратору и помогает подготовить ответ.

## 11. Обязанности Интегратора

Интегратор:

- имеет законное основание для обработки данных Конечных пользователей;
- сообщает Конечным пользователям в своей политике конфиденциальности, что коды подтверждения отправляются через Verificahub;
- передаёт только номера, указанные самим Конечным пользователем;
- передаёт только необходимые данные.
